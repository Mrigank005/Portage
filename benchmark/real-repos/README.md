# Portage on real open-source Stripe apps

Portage's test suite runs on Standin, a local Stripe-compatible server, because Stripe accounts are invite-only in India where Portage is built. To show the scanner and planner on code we didn't write, we also run them on public open-source apps that use Stripe. These results are generated by `npm run benchmark:real` at the commits below; the repositories are only parsed, never installed or run.
